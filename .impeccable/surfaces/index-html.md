# Surface: site institucional (home, produtos, empresa, publicações, contato)

Mode: Persuade (institutional + commercial). Visitors: lab technical leads hunting a kit/REF; managers and institutions evaluating a supplier; researchers. Action: reach the scientific or commercial team (WhatsApp/telefone/e-mail) or open a kit's technical page. Proof: ANVISA BPF, external QA programs, 25 articles, real company figures with source lines. Build path: code-led (no image generation in this harness).

## Direction contract

THESIS: The site is Intercientifica's own kit documentation made monumental: the red kit box, its label and the instructions-for-use leaflet become the design system. REF and Σ (determinações) are first-class typography. It refuses the clinical white page of rounded cards with a stock-baby hero, and the navy/neon DNA sci-fi page.

OWN-WORLD: Box red #DE1E18 owning whole fields (Committed, 30-50% of the first viewport and the closes), coated cool label white, print-black ink, one dark reading-chamber chapter (#0A0C0F) where the only spectral color lives (microsphere sets). Square corners everywhere, 1px ink keylines forming label cells, ISO 15223 style symbol cells (REF, Σ, fabricante). Archivo variable (width axis: expanded caps for display, normal for text) + Martian Mono only for codes, references and measurements.

STORY: In one viewport the visitor knows this is a Brazilian manufacturer of neonatal/prenatal screening kits since 1994; scrolling explains the principle (amostra -> análise -> informação, labeled as illustrative), proves scale and quality with sourced data, lets a lab find any of 9 kits by line, disease or REF, and closes on direct channels.

FIRST VIEWPORT: Full-bleed red box face. Left 7 columns: a white label panel registered on keylines, H1 in expanded Archivo ~5.5rem "Triagem neonatal e pré-natal, fabricada no Brasil", label row cells (fabricante symbol + São José dos Campos, desde 1994, 9 kits, 2 linhas), primary action "Ver catálogo de kits" + secondary "Falar com a equipe científica". Right 5 columns: a dark reading window cut into the box with a live WebGL microsphere field, caption "Representação ilustrativa". Nav as a label strip above.

FORM: IVD kit labeling and IFU leaflet system (ISO 15223 symbols, kit box), position 3 of 7 on my ordered list; seed key e8e8a671. Raises: split-flap (declined) -> codes sit in fixed cells and the product index is a ruled table whose columns never move; ukiyo-e registration (declined) -> entrance prints keylines first, then the red plate, then type, and the keyline never moves; iridescent cloud edge (declined) -> text fields stay achromatic, spectral color confined to the microspheres. Signature interaction: the sticky "Princípio" chapter where one microsphere field reorganizes per step (nuvem -> disco -> 4 conjuntos de analitos -> leitura) with fallback static figures. Motion grammar: registration (keyline draw, plate wipe via clip-path), label-print reveals, one shared expo-out clock.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
